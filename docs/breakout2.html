What this scan does

Screens the NSE top-800 stocks by market cap for a Minervini-style Stage 2 uptrend caught early in a Volatility Contraction Pattern (VCP) — a tightening base right before a possible breakout — plus volume and relative-strength confirmation.

How the score & tags work

Composite score 0-100: Stage 2 trend (48pts) + VCP structure (30pts) + volume dry-up (22pts) + accumulation bonus (RS-line 52-week high +5, U/D volume ratio ≥1.3 +5).

🔥 Prime ≥85   ✅ Developing ≥65   🔶 Partial ≥40   ⬜ Not Ready below 40.

Column glossary

Pivot = high of the last 30-bar base (today excluded) — the breakout trigger price. ✅ valid = closed above pivot and held 2+ days; ❌ failed = broke above pivot in the last 5 days then fell back below.

RS Rating 1-99 = percentile rank of 12-month weighted return in this scan. 📈 RS✦ = stock/Nifty ratio at a 252-week high (early institutional-accumulation signature).

U/D = up-day ÷ down-day volume over 50 bars — above 1.2 is accumulation, below 0.8 is distribution.

Caveats

This is a screening/research page, not an entry signal — a Prime score or ✅ valid breakout still needs a liquidity, earnings and surveillance check before you act. The gated, ready-to-trade version of these same setups lives on the Triggers page.

Universe refreshes each run from Yahoo Finance end-of-day data — treat it as EOD, not real-time. Not financial advice.
